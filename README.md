```
cursor blinks at three
the log line repeats itself
it was my typo
```

An entry for the "Seventeen Syllables of Debugging" bounty on
[make.fun](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605):
a haiku in the classic 5-7-5 form about the smallest, most familiar
debugging moment — staring at a blinking cursor while the same log line
scrolls past again and again, only to discover the bug was a typo all
along.

## How to run

```bash
python3 main.py
```

This writes the haiku (plus a trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then re-reads the
file and verifies its bytes match the haiku exactly, that it is 1–200
characters, and that it is valid UTF-8. Standard library only, no
dependencies.
